# Install Karthikeya Designs Invoice Calculator

This is an installable Progressive Web App (PWA).

## Windows, macOS, and Linux

1. Host the `3d-printer-bill-calculator` folder on HTTPS (or open it through `http://localhost`).
2. Open the app in Chrome or Microsoft Edge.
3. Use the install icon in the address bar, or select **Install Karthikeya Designs Invoice Calculator** from the browser menu.

## Android

Open the hosted app in Chrome and select **Install app** or **Add to Home screen**.

## iPhone and iPad

Open the hosted app in Safari, choose **Share**, then select **Add to Home Screen**.

The app works offline after its first successful hosted load. A plain `file://` page cannot be installed because browsers require HTTPS or localhost for PWA installation.
